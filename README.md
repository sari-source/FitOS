# FitOS

Your personal fitness command center. Track workouts, log nutrition, and stay on target — all in one place.

## Features

- **Profile** — Enter your body stats and goals. FitOS calculates your daily macro targets (calories, protein, carbs, fat) automatically.
- **Training Plan** — Build your weekly workout schedule. Add days, reorder them, and edit individual exercises on the fly. Plans are collapsible for quick viewing.
- **Calendar** — Monthly overview of your training. Tap any day to see what was planned, what you actually lifted, and what you ate. Past days are frozen — editing your profile or plan only affects today and the future.
- **Nutrition** — Log meals manually or scan food photos for AI-powered macro estimation. Real-time progress bars keep you on track.
- **Workout Log** — Record every set, rep, and weight lifted. Build a history of your progress over time.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set up your environment variables:
   Create a `.env` file in the `app` directory with your AI API key (for food photo scanning):
   ```
   VITE_AI_API_KEY=your_api_key_here
   ```

3. Run the dev server:
   ```bash
   npm run dev
   ```

4. Open the provided localhost URL in your browser. Use browser dev tools (F12) to preview in mobile view.
